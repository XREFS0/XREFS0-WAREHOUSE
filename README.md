# XREFS0 WAREHOUSE FREE

A comprehensive warehouse management system built with Rust and Tauri, featuring a modern Arabic RTL interface.

## Features

- Dashboard with real-time statistics
- Sales and invoice management
- Purchase and supplier tracking
- Inventory and stock control
- Point of Sale (POS) system
- Customer and supplier management
- Expense tracking
- Financial reports
- Multi-user support with role-based access
- SQLite database with WAL mode

## Technology Stack

- **Backend:** Rust, Tauri 1.8.3
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite (rusqlite 0.31.0)
- **Runtime:** Tokio 1.52.1
- **Build:** Cargo, npm

## System Requirements

- Windows 10 or later
- WebView2 Runtime (included in Windows 10/11)

## Installation

1. Download the latest release
2. Run `XREFS0 WAREHOUSE FREE.exe`
3. The database will be created automatically on first run
