# Contributing to XREFS0 WAREHOUSE

Thank you for your interest in contributing. Please take a moment to review this document before submitting changes.

## How to Contribute

### Reporting Bugs

- Use the GitHub issue tracker to report bugs.
- Describe the issue in detail: what you did, what you expected to happen, and what actually happened.
- Include your Windows version, the application version, and steps to reproduce the issue.
- Attach screenshots when relevant.

### Suggesting Features

- Open an issue with a clear title and a detailed description of the proposed feature.
- Explain the use case and why the feature would be valuable for warehouse management workflows.

### Submitting Changes

1. Fork the repository.
2. Create a feature branch from `main` (`git checkout -b feature/your-feature-name`).
3. Make your changes with clear, focused commits.
4. Ensure the application builds and runs correctly on Windows.
5. Test the affected workflows (sales, purchases, inventory, reports, settings).
6. Open a pull request with a description of what changed and why.

## Code Guidelines

- Follow the existing code style of the project (Rust backend, HTML/CSS/JavaScript frontend).
- Keep commits small and descriptive.
- Do not commit binaries, databases, or local configuration files.
- Do not include credentials, license keys, or secrets in commits.

## Pull Request Process

1. Update documentation if your change affects user-facing behavior.
2. A maintainer will review the pull request and may request changes.
3. Once approved, the pull request will be merged by a maintainer.

## Questions

If you have questions about contributing, open a discussion or an issue and the maintainers will respond.
