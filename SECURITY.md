# Security Policy

## Supported Versions

Security updates are provided for the latest released version of XREFS0 WAREHOUSE.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue for the vulnerability.
2. Contact the maintainers directly with a detailed description, including:
   - The affected version
   - Steps to reproduce the issue
   - The potential impact
3. Allow reasonable time for the issue to be investigated and fixed before any public disclosure.

## What to Expect

- Acknowledgment of your report in a timely manner.
- Assessment of the reported issue and its severity.
- A fix released as part of a security update when the report is confirmed.
- Credit for the discovery if desired and appropriate.

## Scope

This policy covers the application code distributed in this repository and its official releases. Issues in third-party dependencies should also be reported so they can be evaluated and updated.
